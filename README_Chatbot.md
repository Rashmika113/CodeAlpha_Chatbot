# CodeAlpha_Chatbot

A simple rule-based chatbot built in Python as part of the CodeAlpha Python Programming Internship (Task 4).

## Features
- Responds to greetings, "how are you", "your name", thanks, and farewells
- Simple keyword-based matching using if-elif
- Runs in a loop until the user says a farewell word ("bye", "exit", "quit", etc.)

## Concepts Used
`if-elif`, functions, loops, input/output

## How to Run
```bash
python chatbot.py
```

## Example
```
You: hello
Bot: Hi!
You: how are you
Bot: I'm fine, thanks! How about you?
You: bye
Bot: Goodbye!
```
